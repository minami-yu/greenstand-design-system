# Colors
## Overview
Colors help communicate hierarchy, state, feedback, and brand identity across the product. The color system consists of two layers: Primitive Colors and Semantic Colors. This approach allows color values to evolve without requiring updates throughout designs and code and enhance the maintainability.

<br />
  <StorybookImage
    alt="Design token hierarchy: raw values, primitive tokens, and semantic tokens"
    outline={false}
    src={tokenDiagram}
    background={false}
  />
<br />
<br />

- **Primitive Colors**: Primitive colors are the foundation of the color system (e.g. `color.red-500`). Primitive colors define the available color palette but do not describe how colors should be used.
- **Semantic Colors**: Semantic colors define the role of a color (e.g. `color.text.neutral.primary`). Instead of referencing a raw color value or primitive colors, designers and engineers should reference semantic tokens.

## Accessibility
### WCAG AA
All color combinations used in the product should meet WCAG AA contrast requirements to ensure content remains readable and accessible for a wide range of users.

#### Minimum contrast requirements:
- Normal text: **4.5:1**
- Large text (18px+ or 14px bold+): **3:1**
- Essential UI elements and graphical objects: **3:1**


## Light & dark mode
The current design system is optimized for Light Mode because Treetracker is primarily used outdoors in bright environments where higher screen brightness improves visibility. Dark colors may be used in specific contexts such as camera workflows. A user controlled Dark Mode theme is not currently supported.
