# Typography

## Principles
Typography establishes hierarchy, improves readability, and creates consistency across the product.

- **Readability**: Use appropriate typography sizes and weights to ensure content remains readable across devices and environments.

- **Hierarchy**: Use heading styles, typography weights, and color consistently to establish clear visual hierarchy.

- **Consistency**: Use predefined typography tokens instead of creating custom text styles. Consistent usage makes interfaces easier to scan, maintain, and implement.

- **Accessibility**: Ensure sufficient contrast between text and background colors.

## Tokens

The typography system consists of 4 categories:
- **Heading** for page and section structure
- **Paragraph** for readable content and descriptions
- **Label** for controls and interface elements
- **Numeric** for metrics and quantitative data

## Typogrpahy styling
### Sentence Case
Use sentence case by default for all typography styles unless a proper noun, acronym, or brand name requires otherwise.

- ✅ Upload photos
- ❌ Upload Photos
- ❌ UPLOAD PHOTOS



### Text Decoration
- Reserve underlines for links and interactive text. 
- Avoid using italic text unless required for a specific use case.
