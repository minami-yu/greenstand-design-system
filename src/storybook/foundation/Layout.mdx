# Layout

## Overview
The layout system provides consistent spacing and structure across Treetracker screens. Because the product is used on a wide range of mobile devices, including older and lower end Android phones, layouts should prioritize readability, simplicity, and resilience on narrow screens.


## Grid system
Treetracker uses a flexible mobile grid. Most screens should use a single column layout by default, with additional columns introduced only when they improve usability.

### Columns
The number of columns may vary depending on the content and available space. Use the simplest layout that supports the content. The default layout for most screens is 1 column.

### Margin
Margin defines the horizontal spacing between the screen edge and content. Consistent margins help align content and improve readability across screens.

Gutter defines the spacing between adjacent columns and content areas. Gutters help separate content while maintaining alignment within the grid.
