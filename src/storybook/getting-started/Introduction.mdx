# Getting started

## Overview
The Greenstand Design System provides a shared foundation for designing and building consistent, accessible, and maintainable experiences across Treetracker products. It includes design tokens, foundations, components, implementation guidelines, and documentation to support collaboration between designers and engineers.


## What's design system?
A design system is a collection of reusable standards, components, and guidelines that help teams create consistent user experiences.

## Run storybook locally

- `npm install`
- `npm run build-tokens`
- `npm run storybook:web` — desktop catalog at localhost:6006
- `npm run storybook` — on-device Storybook inside Expo
