# Spinner
## Overview
The spinner is used to indicate that a task is loading or processing. It is a visual representation of the loading state.

## Platform behavior
This component wraps React Native `ActivityIndicator`. `ActivityIndicator` delegates to each OS native spinner. Sizes are aligned to the same diameters on both platforms — no scale transform — but the visual chrome can differ.

<SpinnerPlatformTable />

Web Storybook renders a single web implementation, so it cannot show true iOS vs Android chrome side by side. Use on-device Storybook or simulators to verify platform appearance.
