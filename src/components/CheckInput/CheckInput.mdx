# CheckInput
## Overview
Checkbox allows users to select one or more options from a list or confirm a choice before submitting a form.

Use Checkbox when users need to make multiple selections or explicitly confirm an action, such as accepting terms and conditions. For settings that take effect immediately, use a Switch instead.
