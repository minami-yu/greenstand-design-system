# Switch
## Overview
Switch allows users to turn a setting or feature on and off. It is best used for immediate actions where the change takes effect instantly. Use Switch for binary options such as enabling notifications, auto upload, or location services. For choices that require confirmation or form submission, consider using a CheckInput instead.
