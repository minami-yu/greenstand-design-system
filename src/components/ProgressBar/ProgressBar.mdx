# ProgressBar
## Overview
Progress Bar provides visual feedback on the completion status of a task or process. It helps users understand progress, set expectations, and stay informed while an action is in progress.

Use Progress Bars for tasks with measurable progress, such as uploads, downloads, onboarding flows, or multi step processes.

## Variants

### Value & max
`value` represents the current progress between `0` and `max`. The progress bar fill is calculated as `value / max`. `max` defaults to `100` and can be customized for non percentage based progress, such as multi step flows or file uploads. It is also used by `accessibilityValue` so screen readers can announce progress like "1 of 4".
