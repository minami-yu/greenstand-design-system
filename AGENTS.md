# Codex Repository Instructions

This project is an isolated Expo React Native design system sandbox. It translates W3C Design Tokens through Style Dictionary v4 and renders components in Storybook React Native v8.

## Commands

- `npm run build-tokens`: Compile token JSON from `tokens/` into `src/theme/tokens.ts`.
- `npm run start`: Start the normal Expo application view.
- `npm run storybook`: Start Expo with Storybook enabled via `STORYBOOK_ENABLED=true`.

## Required Token Workflow

Whenever you modify any `.json` file inside `tokens/`, or modify `build.js`, immediately run:

```bash
npm run build-tokens
```

If dependencies are not installed, state that the command could not run and that `npm install` is required first.

## Architecture Rules

- Keep raw design token inputs in `tokens/`.
- Use the W3C Design Token Community Group format with `$value` and `$type` properties.
- Do not manually edit `src/theme/tokens.ts`; it is generated by Style Dictionary.
- Keep `space` token keys as explicit flat scale keys such as `"0"`, `"1"`, `"2"`, `"4"`, `"8"`, `"16"`, and `"n4"`.
- Keep `radius`, `blur`, and visual effect scales as explicit literal or semantic keys such as `"xs"`, `"sm"`, `"md"`, and `"lg"`.
- Use `<Box />` for structural layout primitives.
- Type layout props against `keyof typeof theme.space` and `keyof typeof theme.radius`.
- Prefer React Native array style composition inside primitives.

## Verification

After code changes, run the narrowest relevant check available. For token or build pipeline changes, `npm run build-tokens` is required. For app-level changes, prefer starting Expo or Storybook when dependencies are available.
