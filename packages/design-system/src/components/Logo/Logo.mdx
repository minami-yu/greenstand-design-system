# Logo

## Overview
Logo renders Greenstand and Treetracker brand marks using the variants defined in Figma. Use it directly in app UI, or through TopNavigation logo slots.

<br />
<Canvas of={LogoStories.Playground} />

## Usage
Use Logo to:
- Select the Greenstand or Treetracker mark.
- Switch between Figma color variants.
- Keep app screens from importing brand image files directly.
