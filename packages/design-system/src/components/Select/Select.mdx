# Select

A labeled selection trigger with an optional avatar and a trailing chevron. Import from `@greenstand/design-system`.

<Canvas of={Stories.Playground} />

## Usage
Pass the selected label through `value` and open your option picker with `onPress`. Keep selection and picker state in the caller, and set `expanded` while the picker is open. Use TextField for free-form text.

<Canvas of={Stories.Interactive} />

## States
The placeholder appears without a value. Disabled fields cannot open the picker.

<Canvas of={Stories.Empty} />
<Canvas of={Stories.Disabled} />

<Canvas of={Stories.HiddenLabel} />

`hideLabel` removes the visible label while retaining the required `label` as the accessible name. `leadingContent` accepts decorative artwork such as a country flag; use `avatarSource` for profile images.

## Design guidelines
Use a short label and option names that distinguish the choices. See Accessibility/Overview for button semantics and selection guidance.
