# ListItem

## Overview
ListItem presents a label with optional supporting text, artwork on the left, and information or a control on the right. Rows have a transparent background and an optional divider aligned to the text content.

<Canvas of={ListItemStories.Playground} />

## Usage
Import `ListItem` from `@greenstand/design-system`. Use `onPress` for navigation or actions, and `selected` with `onSelectedChange` for selection controls.

```tsx
<ListItem
  label="Notifications"
  paragraph="Receive capture updates"
  leadingElement="icon"
  leadingIcon="heart-outline"
  trailingElement="switch"
  selected={notificationsEnabled}
  onSelectedChange={setNotificationsEnabled}
/>
```

Both sizes use `labelM`. Large supporting text uses `paragraphS` with a 2 px gap. Rows expand for wrapping text and font scaling. `showParagraph=false` hides the large paragraph and the caption in `badgeAndText`, matching Figma's shared boolean property. Other caption variants remain visible.

## Selection and states
These examples are interactive. Checkbox and switch rows toggle; radio rows belong to a single-choice group. Keep state in the caller and supply `onSelectedChange`. Disabled rows cannot change state. Selection variants use `onSelectedChange` rather than `onPress`.

## Destructive actions
Use `tone="destructive"` for destructive actions such as Log out. Both the label and leading icon use semantic error colors. Leading icons use `icon.md` (20 px) in both compact and large rows.

## Divider
The divider starts after the leading artwork and extends to the right edge. Set `showDivider=false` for the final item or when a surrounding container provides separation.

## Design guidelines and known difference
Use the smallest amount of trailing information needed. Choose a large row when supporting text or a thumbnail is important. Keep related radio rows in a named radio group. Accessibility/Overview documents row labels, roles, checked state, and touch targets.

The Figma ListItem references a square CheckInput, while the existing shared CheckInput has a circular indicator. ListItem reuses the current shared component and its behavior; this existing design difference is not changed here. The shared Switch also currently renders a 28 px track rather than the 24 px track in this Figma example.
