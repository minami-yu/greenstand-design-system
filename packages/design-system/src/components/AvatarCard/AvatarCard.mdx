# AvatarCard

## Overview
AvatarCard displays a photo avatar or circular icon action with a label inside a selectable card surface.

<br />
<Canvas of={AvatarCardStories.Playground} />

## Usage
Use AvatarCard for choosing an identity, profile, or user-like option.

The card follows the Figma spec as a 160 × 160 square and composes the `Avatar`
with its `xl` size so the avatar visual stays consistent with the updated
identity-selection pattern.

## Add actions
Use `visualElements="button"` for an add action in the same grid as existing profiles.
The circular surface matches the 88px avatar and defaults to the `add` icon; `icon` accepts an `IconName`.
The whole card is one press target. Pass `onPress` to connect the action.

<Canvas of={AvatarCardStories.AddUser} />

## Labels and states
Labels wrap to two lines. Outlined cards use the medium radius; cards without an outline use the small radius. Existing selected treatments remain supported for identity selection.

<Canvas of={AvatarCardStories.WrappedLabel} />
