# ImageGroup

A compact summary of saved images. Import `ImageGroup` from `@greenstand/design-system` and pass an `images` array.

<Canvas of={Stories.Single} />

## Variants and states
Displays up to three overlapping thumbnails. Additional images appear as a `+N` count; an empty array renders no thumbnails.

<Canvas of={Stories.Stack} />
<Canvas of={Stories.Overflow} />
<Canvas of={Stories.Empty} />

<ArgTypes of={Stories} />

## Guidelines
Use actual captured images in consistent order. This component summarizes a collection and is not itself a gallery button. The accessible label announces the total number of saved photos; see Accessibility/Overview.
