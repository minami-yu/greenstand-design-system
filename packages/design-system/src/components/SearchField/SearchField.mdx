# SearchField

## Purpose and usage
A search input with default, outlined, and surface treatments. Pass value and onChangeText for controlled usage; entered text replaces the voice action with a clear action. Set `showAudio={false}` for search-only layouts such as the full tree list.

<Canvas of={Stories.Playground} />
<Canvas of={Stories.Interactive} />

## States and guidelines
Use `outlined` against plain page backgrounds, `surface` when the white field needs no border, and `default` for the subtle neutral fill. Supports native TextInput props, including editable and placeholder.

See Accessibility/Overview for accessibility guidance.
